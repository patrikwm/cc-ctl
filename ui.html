What is this correlating? (local $ share, last 5h)

This is NOT the metered window %. Two reasons they diverge: (1) the meter is computed server-side over rolling windows and dollar spend is not proportional to it; (2) cache reads cost ~10× less per token in $ but still consume metered quota, so a session that looks nearly free in dollars can still be expensive against the meter. Cache-read tokens are shown in the table for that reason.
